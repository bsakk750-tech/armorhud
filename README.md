# Armor HUD (Fabric 1.21.11)

Клиентский Fabric-мод, который показывает четыре слота брони справа от хотбара.

* Иконки всегда видимы. Пустой слот отображается затемнённой иконкой соответствующей части брони.
* Для надетого предмета поверх иконки выводится остаток прочности в процентах.
* Цвет процента: белый (>50%), жёлтый (21–50%), красный (<=20%).
* Настройки открываются через кнопку мода в **Mod Menu**. Отдельная клавиша не регистрируется.
* Конфигурация сохраняется в `config/armorhud.json`.

## Настройки

В Mod Menu доступны ориентация (горизонтальная/вертикальная), смещение по X/Y, размер иконок и расстояние между ними. Значения ограничены безопасным диапазоном, чтобы HUD не ломал интерфейс.

## Сборка

Требуется Java 21 и Gradle (или Gradle Wrapper). Выполните `gradlew build`; готовый JAR появится в `build/libs`.
